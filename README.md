# PLCJS_ETH_MODULE_8AIV_D4MG_STM32F407VGT6

Прошивка Ethernet-модуля PLCJS 8AIV: 8 изолированных аналоговых входов
напряжения на одном `ADS8688`, STM32F407VGT6, коммутатор KSZ8863, Modbus TCP.
Сеть, Modbus, обнаружение (PDP), контракт с загрузчиком и светодиоды общие с
семейством (8AIC / 8UAI); аналоговый тракт — простое сканирование по таймеру.
Плата также служит стендом для отладки тракта ADS8688, который использует
прошивка 8UAI.

Схема: `DOC/SCH_8AIV.pdf`. Идентификация образа: `product_id 0x504C0805`,
`hw 01.01`, ID модуля (IR125) `0x08A5`. Образ запускается только через
загрузчик (`BOOTLOADER_PLCJS_ETH_MODULE_STM32F407VGT6`, строка `8aiv` в
`scripts/variants.csv`).

## Аппаратная часть

| Узел | Значение |
|---|---|
| АЦП | ADS8688, внутренний ИОН 4,096 В (REFSEL = GND), программный RST (RST/PD подтянут к питанию) |
| Шина | SPI1 PA5 SCLK / PA6 MISO / PB5 MOSI, CS PA9, через изолятор CA-IS3741LB, 10 МГц, режим 1 |
| Входная цепь | Vin -> 1 кОм (2512) -> узел (120 кОм на GND, TVS 12 В) -> 1 кОм -> AIN_nP; AIN_nGND -> 2 кОм -> GND |
| Светодиоды каналов | AI0 PB15, AI1 PB14, AI2 PB10, AI3 PE15, AI4 PE14, AI5 PE13, AI6 PE12, AI7 PE11 |
| Канал ADS8688 для AI0..AI7 | 5, 4, 3, 2, 0, 1, 7, 6 (`BOARD_ADC_MAP`) |

## Режимы

| Режим | Сигнал | Диапазон ADS8688 |
|---|---|---|
| 0 OFF | | |
| 1 | 0..10 В (по умолчанию) | 0..10,24 В |
| 2 | 2..10 В, ниже 1,8 В — обрыв | 0..10,24 В |
| 3 | 0..5 В | 0..5,12 В |
| 4 | ±10 В | ±10,24 В |
| 5 | ±5 В | ±5,12 В |

Коэффициент передачи цепи около 0,9898 (делитель плюс нагрузка АЦП); прошивка
обращает полную модель, затем применяет калибровку канала
`V = gain · Vin + offset` и необязательное инженерное масштабирование.

## Сбор данных

TIM2 задаёт один кадр ADS8688 каждые 39,0625 мкс; 8 входов опрашиваются по
кругу (каждый вход раз в 312,5 мкс). Окно — 2560 слотов = 100,000 мс
(320 выборок на вход, целое число периодов 50 и 60 Гц) или 512 слотов =
20,000 мс (64 выборки, только 50 Гц). Между окнами движок применяет заказанные
смены диапазона и читает обратно один регистр диапазона (по кругу), поэтому
потеря конфигурации ADS8688 обнаруживается и восстанавливается (ADC_FAIL на
5 с, IR133 считает расхождения). На время стирания Flash (сохранение
настроек) сканирование приостанавливается, окно начинается заново.

## Карта Modbus

Полная карта — комментарий в `Application/modbus/modbus_app.h`.

| Регистры | Содержимое |
|---|---|
| HR 0..7 / 8..15 / 16..23 | показание, мВ (RO) / режим / фильтр EMA, мс |
| HR 24..87 | float32 ×8 каждый: gain, offset (В), масштаб low, масштаб high |
| HR 101..119, 130, 131 | общие для семейства: режим LED, slave id, порт, IP, маска, шлюз, режим сети, SAVE `0xA5A5`, REBOOT `0xB00B` / BOOT `0xB007` / сброс KSZ `0x8863`, FACTORY `0xDEAD`, температура, команда канала |
| HR 132..154 | окно интегрирования, модель входной цепи, диагностика (сервис) |
| IR 300..331 | значение и raw (В), float32 ×8 |
| IR 332..411 | статус, счётчик, средний / мин / макс код, шум RMS, счётчики насыщения, состояние |
| IR 120..134 | прошивка, uptime, ID модуля, температура, флаги, выборки, сохранения, окна, переполнения, ошибки диапазонов, попытки запуска |

Биты статуса канала: 0 NO_DATA, 1 OVERRANGE, 2 UNDERRANGE, 3 WIRE_BREAK,
4 ADC_CLIP, 5 CONFIG_ERR, 6 ADC_FAIL, 7 OFF.

## Образ

| Поле | Значение |
|---|---|
| `fw_header` product_id | `0x504C0805` |
| hw_revision / fw_version | `0x0101` / `0x0100` |
| Начало Flash | `0x08040000`, 256 КБ; заголовок по смещению `0x200` |
| Настройки | сектор 10 `0x080C0000`, CRC32, magic `0x08A54A57` |

## Сборка и тесты

```
cmake --preset Debug && cmake --build --preset Debug      # или Release
```

Host-тесты математики (нативный gcc):

```
cmake -S tests -B build/host-tests -G Ninja -DCMAKE_C_COMPILER=gcc
cmake --build build/host-tests
ctest --test-dir build/host-tests --output-on-failure
```

Прошивка только по SWD оставляет плату в загрузчике (проверка CRC metadata);
используйте OTA или `scripts/service_flash.ps1` загрузчика.

## Состояние

Оба пресета собираются без предупреждений, host-тесты проходят. На железе
ничего не запускалось: нужно измерить тайминги SPI через изолятор, нагрузку
от прерывания (около 10 % CPU), реальный коэффициент входной цепи и влияние
резистора AIN_nGND, а также точность.
